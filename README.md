📊 Trading Report Automation – Blue Prism Project

A Blue Prism automation that generates the monthly trading report for the **Amman Stock Exchange**, processes raw financial data, prepares bank and insurance summaries, creates visual charts, applies price-comparison logic, and automatically emails the final report to stakeholders.

---

 🔷 **Project Overview**

The automation performs the following tasks:

 1️⃣ **Receive Monthly Raw Data**
- Bot picks up the new trading dataset from the predefined source (email/shared folder).  
- Validates file format and logs the transaction.

 2️⃣ **Process & Clean Financial Data**
- Removes unnecessary columns  
- Standardizes formats  
- Adds new analytical fields used in reporting and chart generation  

 3️⃣ **Generate Trading Reports**
- Creates:
  - Monthly trading summary  
  - Bank comparison report  
  - Insurance companies report  
  - Price comparison sheet  
- Populates Excel templates with structured and validated data

 4️⃣ **Create Visual Charts**
- Uses Excel automation to generate:
  - Line charts  
  - Bar charts  
  - Trend analysis graphs  

 5️⃣ **Assemble the Final Monthly Report**
- Combines all sheets  
- Ensures accuracy and formatting  
- Saves the final output to a defined directory

 6️⃣ **Send Report Automatically**
- Sends email with:
  - Subject: **“Monthly Trading Report – Automated Output”**
  - Attachment: Final Excel report  
- Logs completion and error handling states



 🛠️ **Tools & Technologies**
- **Blue Prism**
- **Excel Automation**
- **Outlook (Email Automation)**
- **Data Processing & Reporting**
